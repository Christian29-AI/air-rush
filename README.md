# Air Rush · Air Hockey Arcade

Juego de air hockey 2D para Godot. Juega contra Air Bot en tres dificultades o con otra persona en el mismo equipo.

Abre `project.godot` en Godot 4.7.2 y pulsa **F5**. El juego abre directo en el menú.

- **Rojo:** WASD. También puedes activar el ratón en Opciones.
- **Azul en jugador local:** flechas.
- **Pausa:** P o Esc.

Cada gol con el disco principal vale 50 puntos. Gana quien meta siete goles. Si la partida llega a 02:50, se activa el modo de fichas.

Consulta [LEEME.md](LEEME.md) para ver todos los controles, poderes y reglas.
